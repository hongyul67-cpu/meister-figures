마이스터고 신청서 그림 — 고치는 법 (2026. 11. 13.)
================================================

■ 폴더 안에 있는 것
  · 그림(png)            : 신청서(한글)에 들어간 그림
  · 원본(html)           : 그림을 만든 원본. 글자·숫자는 모두 여기 들어 있음
  · 자료\글자\…txt       : 그림 하나에 든 글자를 전부 뽑아 놓은 것 (찾아보기·검토용)
  · 자료\숫자출처\…csv   : 서론 2026 그림 10장의 숫자 — 값·단위·기준 시점·모집단·출처·링크 (엑셀로 열림)
  · 자료\그림자료_정리_v?.xlsx : 그림 목록 + 숫자·출처 전체 + 이 안내 (한 파일)
  · 자료\다시그리기.py   : 고친 html 을 png 로 다시 만드는 프로그램

■ 글자나 숫자 하나를 고치고 싶을 때
  1) 「글자」 파일이나 정리표에서 고칠 글자를 찾는다
  2) 같은 이름의 html 을 메모장(또는 VS Code)으로 연다 → Ctrl+F 로 그 글자를 찾아 고치고 저장
     (배치도는 plan_c = 창조관 1층, plan_m1 = 명장관 1층, plan_m2 = 명장관 2층)
  3) 명령 창(PowerShell)에서 자료 폴더로 가서
        python 다시그리기.py "..\서론_2026\06_11쪽_경기제조AI.html"
     → 같은 폴더의 png 가 새로 만들어짐(원래 png 는 그 폴더 _백업 에 시각 붙여 남음)
  4) 브라우저로 html 을 열어 먼저 눈으로 보고, 글자가 넘치면 글자를 줄인다
     (그림 크기는 원래와 같게 나오므로 한글 문서의 쪽 수가 바뀌지 않음)
  5) 신청서(한글)의 그림을 지우고 새 png 를 같은 너비로 넣는다

■ 숫자를 고칠 때 꼭 볼 것 (2026-11-13 점검에서 나온 것)
  · 모집단이 다른 숫자를 나란히 두지 않는다
      예) 경기 피지컬 AI 활용 12.5% = 스마트공장 기초 이상 「앞선 기업 200곳」
          정부 AI 도입률 10% = 「전국 중소 제조기업 전체」의 2030 목표(현재 1%)
      → 둘을 같이 쓸 때는 「현재 → 목표」와 조사 대상을 함께 적는다
  · 합계·비율은 csv 의 「계산」 줄로 다시 맞춰 본다
      (비전2030펀드 2,800+2,550+2,500+1,500 = 9,350억, 공급기업 17개 시도 합 2,865개 등)
  · 기사 숫자는 원문 표현까지 확인한다
      (예: 「전국 첫 AI 특구」가 아니라 「지역특화발전특구 최초의 AI 특구」)
  · 출처를 못 찾은 숫자는 그림에 넣지 않는다

■ 쪽 번호(파일 이름의 ○○쪽)는 2026. 11. 13. 제출용 v26 의 인쇄 쪽 번호입니다.
